# calculo-peso-linguice
## Descrição do Problema
Sistema para calcular o peso de peças de linguiça assada na chapa, considerando o peso do espeto de madeira.
## Requisitos
- Subtrair o peso do espeto do peso total.
- Calcular a média de 3 espetos.
## Exemplo de Uso
Entrada: [(500, 20), (520, 20), (480, 20)]
Saída: Peso líquido total: 1460g. Média por espeto: 486.67g
